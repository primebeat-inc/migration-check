利用条件と扱う情報

ベータ版の間の暫定の内容です。変えるときはこのページを書き換え、日付を改めます。変えた跡は GitHub の履歴に残ります。最終更新: 2026年10月27日

提供するもの

  • 入れられたサイトについて、Cloudflare とメールサービスへ移せるかを、外から見える情報をもとに判定します。無料です。
  • 判定は目安です。正しさや、判定にもとづいて行った作業の結果は保証しません。
  • 予告なく、内容を変えたり、提供を止めたりすることがあります。

してはいけないこと

  • ご自身が管理していないサイトの弱点を探し、攻撃の下調べに使うこと
  • プログラムで自動に、または大量に判定を送ること（接続元ごとに1分10回までに制限しています）
  • このサービスや、判定で調べるサイトの動きを妨げること

どこで何が動き、誰に何が届くか

判定の部分動く場所と、届く先
DNS・メール・SPF・DKIM・DMARCあなたのブラウザの中で動きます。問い合わせは Cloudflare の公開 DNS（cloudflare-dns.com）に届きます。
ドメインの登録事業者と移管のロックあなたのブラウザの中で動きます。問い合わせは IANA と、そのドメインの登録所の RDAP に届きます。.jp は問い合わせません。
サイト作成サービスか、Cloudflare を通っているかあなたのブラウザの中で、DNS の向き先から判定します。
WordPress かあなたのブラウザが、そのサイトから WordPress の画像を1つ読み込めるかで見ます。読み込みはあなたのブラウザから行われます。
判定の規則（型と手順を決める部分）あなたのブラウザの中で動きます。
PHP の版・管理画面（手順書のみ）DNS に確認の値を足して持ち主だと確かめたドメインだけを、Prime Beat のサーバー（Cloudflare Workers）で調べます。サーバーは、そのサイトに最大5回アクセスします。

無料の判定では、Prime Beat のサーバーにドメインは届きません。

Prime Beat が扱う情報

情報使い道と、残す期間
持ち主の確認と詳しい調べで届くドメイン確認の値を作ること、DNS の値を確かめること、詳しく調べることに使います。同じドメインの調べを使い回すため、結果を10分ほど一時的に置くことがあります。それ以外は残しません。
接続元の IP アドレス回数の制限のためにだけ使います。直近60秒の回数を数えるあいだメモリに置き、記録には残しません。IPv6 は先頭の64ビットにまとめて扱います。
件数ブラウザから、判定の型、メールの引っ越しが要るか、相談のリンクが押されたことだけが届きます。持ち主の確認と詳しい調べの件数もあわせて、日ごとに数えます。ドメインと接続元は含みません。
相談のメールメールでいただいた内容は、ご相談への返事と見積のためにだけ使います。

詳しい調べでは、公開されているページへの普通のアクセスだけを行います。ボット対策の確認画面は突破しません。いただいた情報を第三者に渡すことはありません。

手順書（有料）

コードと、確かめ方

このサービスのコードは GitHub で公開しています（MIT ライセンス）。ブラウザに配られているファイルがリポジトリの版と同じかは、リポジトリの npm run verify で確かめられます。サーバーで動いているコードが公開のものと同じことは、仕組みの上で証明できません。そのため、サーバーに任せるのは、持ち主の同意を得たサイトの詳しい調べだけにしています。
