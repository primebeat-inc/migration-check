利用条件と扱う情報

ベータ版の間の暫定の内容です。変えるときはこのページを書き換え、日付を改めます。変えた跡は GitHub の履歴に残ります。最終更新: 2026年10月27日

提供するもの

  • 入れられたサイトについて、Cloudflare とメールサービスへ移せるかを、外から見える情報をもとに判定します。無料です。
  • 判定は目安です。正しさや、判定にもとづいて行った作業の結果は保証しません。
  • 予告なく、内容を変えたり、提供を止めたりすることがあります。

してはいけないこと

  • ご自身が管理していないサイトの弱点を探し、攻撃の下調べに使うこと
  • プログラムで自動に、または大量に判定を送ること（接続元ごとに1分10回までに制限しています）
  • このサービスや、判定で調べるサイトの動きを妨げること

どこで何が動き、誰に何が届くか

判定の部分動く場所と、届く先
DNS・メール・SPF・DKIM・DMARCあなたのブラウザの中で動きます。問い合わせは Cloudflare の公開 DNS（cloudflare-dns.com）に届きます。Prime Beat のサーバーには届きません。
ドメインの登録事業者と移管のロックあなたのブラウザの中で動きます。問い合わせは IANA と、そのドメインの登録所の RDAP に届きます。.jp は問い合わせません。
サイトの中身（CMS・PHP の版・管理画面）Prime Beat のサーバー（Cloudflare Workers）で動きます。ドメインが届きます。サーバーは、そのサイトに最大5回アクセスします。
判定の規則（型と手順を決める部分）あなたのブラウザの中で動きます。

Prime Beat が扱う情報

情報使い道と、残す期間
サイトの中身を調べるために届くドメイン調べるために使います。同じドメインの調べを使い回すため、サイトの結果を10分ほど一時的に置くことがあります。それ以外は残しません。
接続元の IP アドレス回数の制限のためにだけ使います。直近60秒の回数を数えるあいだメモリに置き、記録には残しません。IPv6 は先頭の64ビットにまとめて扱います。
件数ブラウザから、判定の型、メールの引っ越しが要るか、相談のリンクが押されたことだけが届きます。日ごとの件数として数えます。ドメインと接続元は含みません。
相談のメールメールでいただいた内容は、ご相談への返事と見積のためにだけ使います。

判定で調べるサイトには、公開されているページへの普通のアクセスだけを行います。ボット対策の確認画面は突破しません。いただいた情報を第三者に渡すことはありません。

コードと、確かめ方

このサービスのコードは GitHub で公開しています（MIT ライセンス）。ブラウザに配られているファイルがリポジトリの版と同じかは、リポジトリの npm run verify で確かめられます。サーバーで動いているコードが公開のものと同じことは、仕組みの上で証明できません。そのため、サーバーに任せるのはサイトの中身の読み取りだけにしています。
