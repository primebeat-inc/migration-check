サイトとメールの引っ越し判定（ベータ版）

今のレンタルサーバーから、サイトとメールを移せるかを無料で判定します。サイトの移し先は Cloudflare、メールの移し先は Google Workspace などを考えています。URL を入れると、移すときに気をつける点と、持ち主がやる手順が分かります。

無料・登録不要・パスワードは要りません・10秒ほど

弱点を探す診断ではありません。サイトの置き場所を変えて急ぎの更新を減らし、メールの引っ越しとレンタルサーバーの解約まで迷わず進めるための判定です。

運営: Prime Beat株式会社（代表 渋谷竜響）／判定に使うのは、公開の DNS とサイトの公開ページだけです

よくある質問

無料ですか

はい。判定は無料で、登録も要りません。引っ越しを頼むときだけ、サイトの作りとメールの状態を確かめてから見積をお出しします。

入れたドメインはどう扱われますか

DNS とメールの判定はブラウザの中だけで行い、Prime Beat には届きません。サイトの中身を調べるためにドメインだけが Prime Beat のサーバーに届きますが、保存しません（同じドメインの調べを10分ほど使い回すための一時的な置き場を除きます）。

「気をつける点」が無ければ安全ですか

いいえ。外から見える範囲では見つからなかった、という意味です。管理画面のパスワードの強さ、プラグインの更新漏れ、サーバーの中のプログラムの弱点は調べていません。

自分で移せますか

はい。結果の「持ち主がやる手順」を上から進めれば、自分で移せます。メールがレンタルサーバーにあるときは、レンタルサーバーを解約する前にメールを移してください。解約するとメールも消えます。

判定が正しいか確かめるには

コードと判定の規則を GitHub で公開しています。手元のパソコンで同じ判定を動かして、結果を見比べられます。

運営会社を信頼しなくても確かめられること

  • DNS・メール・ドメインの登録情報の判定は、このページを開いたブラウザの中で動きます。問い合わせ先は Cloudflare の公開 DNS と、ドメインの登録所（RDAP）で、Prime Beat のサーバーには届きません。
  • サイトの中身（CMS・PHP の版・管理画面）は、ブラウザの決まりで他のサイトを読めないため、ドメインだけを Prime Beat のサーバーに送って調べます。結果は保存しません。この部分だけは、サーバーで動くコードを信頼する必要があります。
  • どこに何を送っているかは、ブラウザの開発者ツールのネットワーク欄で見られます。
  • ブラウザで動くコード、判定の規則、サーバーのコードは GitHub で公開しています（MIT ライセンス）。いま動いている版: 確かめています。配られているファイルがその版と同じかは、リポジトリの npm run verify で確かめられます。
  • Prime Beat のサーバーを使わずに、手元のパソコンで全部を動かすこともできます。手順はリポジトリの README にあります。
